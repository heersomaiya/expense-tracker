💰 Expense Tracker

A simple and user-friendly web-based Expense Tracker built using Python, Flask, and MongoDB.  
The application allows users to add, view, edit, and delete their daily expenses, with all data securely stored in MongoDB.

---

🎯 Project Objective

The main objective of this project is to build a simple web application that demonstrates how a Python Flask backend can interact with a MongoDB database to perform CRUD operations.

---

🚀 Features

- Add new expenses
- View all recorded expenses
- Edit existing expenses
- Delete expenses
- Store expense date
- Categorize expenses
- Store data in MongoDB
- Clean and simple web interface

---

🛠️ Technologies Used

HTML --> Web page structure
CSS --> Styling and user interface
Python --> Backend programming
Flask -->  Web framework
MongoDB Atlas --> Database
PyMongo --> MongoDB connection
Jinja2 --> Dynamic HTML rendering
